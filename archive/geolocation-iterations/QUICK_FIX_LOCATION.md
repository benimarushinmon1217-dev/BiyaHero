# 🚀 Quick Fix - Location Showing "Boac"

## ⚡ Immediate Solution

**Don't use the location button!** Instead:

### ✅ Manual Entry (Recommended)
1. Click in the "Saan ka galing?" field
2. Type your location: `Lipa City` or `SM City Lipa`
3. Select from dropdown suggestions
4. Look for green checkmark ✓

**That's it!** Much more reliable than GPS.

---

## 🔧 If You Want to Fix GPS

### Windows Quick Fix:
```
1. Press Windows key
2. Type "Location settings"
3. Turn ON "Location services"
4. Turn ON "Let apps access your location"
5. Restart browser
```

### Browser Quick Fix:
```
Chrome/Edge:
1. Click lock icon 🔒 in address bar
2. Click "Site settings"
3. Location → Allow
4. Refresh page

Firefox:
1. Click lock icon 🔒 in address bar
2. Click "Connection secure" → More information
3. Permissions → Location → Allow
4. Refresh page
```

---

## 🎯 Why This Happened

Your browser thought you were in **Boac, Marinduque** instead of Batangas.

**Common causes**:
- ❌ VPN active
- ❌ Wrong WiFi location database
- ❌ IP-based location (ISP routing)
- ❌ Cached old location

**The fix I applied**:
- ✅ App now validates location is in Batangas
- ✅ Shows warning if outside Batangas
- ✅ Won't let you use wrong location
